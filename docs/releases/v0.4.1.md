# Codex Touch Pet v0.4.1

版本：0.4.1 (5) · 2026-10-20

## 本版更新

- 修复长期 IPC 连接逐条处理消息时临时 Foundation 对象累积的问题；新增直接运行正式客户端的物理内存回归和扩展压力测试。
- 降低动画重复绘制和布局开销：图片、文字及可见性不变时不重复提交；狐狸在固定 48×30pt 的局部视图中移动，道具场景每 tick 只提交最终姿态。保留 30Hz 位移与原有动画帧率。
- 包含受限的软件图标道具原型：仅使用白名单工具元数据，最多显示三个道具及溢出计数。未知软件显示通用图标，不读取工具参数或返回正文猜测软件身份。
- 补充任务/道具生命周期、断线清理、静态/减少动态/安静模式、固定尺寸及无变化帧的回归测试。

## 性能证据与边界

- 同机实际混合使用窗口，各取 24 个有效 5 秒 CPU 样本，主进程均值从约 13.40% 降至 5.28%（按一个逻辑核心容量计）。这不是严格同负载 A/B、纯空闲、电池或温度验收。
- 修复后的实际 App 单独观察 180 秒，物理内存采样约 33.8–35.1MiB，结束约 35.1MiB；生命周期启动瞬时峰值约 353MiB。短时结果不能代替多小时观察，也不能证明历史 3.41GB 的全部原因已排除。
- 隔离 socket 的正式客户端 4,000 条消息回归及 12,000 条扩展测试均已通过。真实 IPC 的开始/在线结束生命周期已观察；两个准确软件身份、多软件并行动作及实体动画手感仍待验收。

## 下载与安装

交付文件：

- `Codex-Touch-Pet-v0.4.1-macos-arm64.zip`：内含 `Codex Touch Pet.app`，以及随包 README 和 NOTICE。
- `SHA256SUMS.txt`：校验下载包和本发布说明的 SHA-256。
- `RELEASE_NOTES.md`：本说明的独立副本。

仅提供 Apple Silicon（arm64）构建，最低 macOS 13.0。完整界面需要实体 Touch Bar；不具备相关私有能力时降级为菜单栏。解压后将 App 拖入“应用程序”；如有旧实例，先从其菜单退出，再替换。

包采用 ad-hoc 签名，**未使用 Developer ID 签名、未经过 Apple 公证**；首次启动可能需要在系统设置中允许打开。不建议为运行本工具关闭系统安全功能。

在三个下载文件所在目录执行：

```bash
shasum -a 256 -c SHA256SUMS.txt
```

## 兼容性与许可

使用 macOS Touch Bar 与 Codex Desktop 的私有接口，兼容性可能随系统或 Codex 更新变化，仍属实验版本。无需 API Key，不访问在线模型或天气服务。

许可证仍待项目所有者确认，详见 `NOTICE.txt`；本次发布不擅自授予复制、修改或再分发许可。

## 从源码验证

需要 macOS 上可用的 Xcode Command Line Tools / Swift 编译器。串行执行，避免多个目标同时写同一构建目录：

```bash
make test-app test-interface test-idle test-tools build-live-tool-test test-ipc-memory package
.build/direct/pet-tool-live-tests --self-test
.build/direct/pet-ipc-memory-tests --stress
```

上述命令不连接真实 Codex IPC；内存测试创建隔离的本地 Unix socket。`pet-tool-live-tests` 不带 `--self-test` 时才会执行明确的真实只读 IPC 观察。测试生成的离屏图不等于实体 Touch Bar 验收。
