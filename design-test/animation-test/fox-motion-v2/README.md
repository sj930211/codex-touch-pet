# Directional motion test v2

This folder records the longer run-cycle redesign and the generated visual
references. The production frames under `Resources/Fox/` use the previously
approved, normalized right-facing run row plus its exact horizontal mirror for
the left-facing row. That deterministic pair keeps the fox identity, baseline,
and Touch Bar scale stable while the motion director selects the correct
direction.

The generated strips are retained as future art direction references. They are
not loaded directly by the app because raw image-generation strips can contain
overlapping poses and must pass another cleanup/continuity review first.
